원격 낚시 방법

리버티 모바일 앱에서 낚시 설정
PC가 켜져 있다면, 모바일 앱에서 원하는 캐릭터를 선택하여
리니지2 실행부터 원격 낚시 시작까지 진행할 수 있습니다.
이런 상황에 사용하세요
출근했는데 서버 점검으로 낚시 중이던 캐릭터가 접속 종료되었나요?
이제 PC만 켜져 있다면, 리버티 모바일 앱에서 다시 캐릭터를 접속시켜 원격 낚시를 시작할 수 있습니다.
1. 리버티 원격 매니저 실행
클라이언트가 설치된 폴더로 이동하면 RemoteManager.exe 파일이 있습니다.
해당 파일을 실행하면 화면 우측 하단 시계 영역에 트레이 아이콘으로 실행됩니다.
2. PC 등록 코드 확인
트레이 아이콘을 마우스 우클릭한 뒤 등록 코드 확인 메뉴를 눌러주세요.
아래와 같은 등록 코드 창이 열립니다.
이 창을 닫지 말고 그대로 열어둔 상태에서 모바일 앱을 실행해주세요.
3. 모바일 앱에서 PC 등록
모바일 앱 메뉴에서 원격 낚시로 이동한 뒤 PC 등록 버튼을 터치합니다.
PC 등록 코드 창에 표시된 코드를 직접 입력하거나,
QR코드 스캔 기능을 사용하면 더 쉽게 등록할 수 있습니다.
4. 원격 낚시 시작
PC 등록이 완료되면 모바일 앱과 리버티 원격 매니저가 서로 연동됩니다.
이후 PC가 켜져 있고 원격 매니저가 연결되어 있다면, 앱에서 원하는 캐릭터를 선택해 원격 낚시를 시작할 수 있습니다.
사용 전 확인사항
ㆍ원격 낚시를 사용하려면 PC가 켜져 있어야 합니다.
ㆍ리버티 원격 매니저가 실행 중이어야 합니다.
ㆍ자동 실행을 켜두면 Windows 시작 시 원격 매니저가 자동으로 실행됩니다.
ㆍ캐릭터 인벤토리에 낚싯대와 미끼가 있어야 낚시가 가능합니다.
ㆍ낚싯대와 미끼를 착용하지 않은 상태여도 자동 장착을 시도합니다.
ㆍ원격 기능은 낚시 시작과 상태 확인만 지원합니다.
이제 밖에서도 편하게 낚시하세요!
서버 점검, 접속 종료, 외출 중에도
리버티 모바일 앱으로 간편하게 원격 낚시를 시작할 수 있습니다.
