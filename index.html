다운로드

잠깐!! 윈도우 디펜더 설정 했습니까?
다운로드 전 반드시 <디펜더 설정>을 보시고 꼭 설정하세요.


약 35GB 이상의 공간이 필요하며, Windows 7/8 은 설치가 불가능합니다.



1. 아래의 이미지를 클릭해서 다운로드 받으세요.


2. 다운로드가 완료되면, 다운로드 받은 LibertyInstall.exe 파일을 실행해주세요.
2-1. Windows의 PC 보호 창이 뜨면 [추가 정보] -> [실행] 버튼을 눌러주세요.


3. 리버티 클라이언트 설치를 시작합니다. [다음] 버튼을 눌러주세요.


3-1 .NET 8.0 런타임 설치가 필요하므로 자동으로 설치됩니다.


4. 클라이언트를 설치할 경로를 선택해 주세요.
- (기본: 설치파일 위치\Liberty Classic, 여유 공간이 충분한 드라이브 권장 - 34gb이상)






5. 이용약관을 모두 읽고 [동의함] 버튼을 누르면 설치가 시작됩니다. - 스크롤을 내려야 합니다.


6. 클라이언트 파일을 분할 다운로드 받습니다.


7. 클라이언트 다운로드 및 설치가 완료되면 런처를 다운로드 받습니다.


8. 설치가 완료되었습니다. [마침] 버튼을 누르면 런처가 실행됩니다.


9. 설치가 완료되었습니다. [마침] 버튼을 누르면 런처가 실행됩니다.
